CONTROL PLANE · OVERVIEW

Control Plane คืออะไร

Network layer แบ่งงานเป็น 2 ระนาบ — routing อยู่ใน control plane และ forwarding อยู่ใน data plane

Control plane

Routing: กำหนดเส้นทางที่ packet จะเดินจากต้นทางถึงปลายทาง — คำนวณนานกว่า แล้วนำผลไปเติมใน forwarding table

Routing เป็นงานของ control plane · Forwarding เป็นงานของ data plane

TWO KEY FUNCTIONS

Routing vs Forwarding

Routing หา “เส้นทางที่ดี” · Forwarding พา packet ผ่าน router แต่ละตัว

Forwarding

ย้าย packet จาก input ของ router ไปยัง output ที่เหมาะสม

ทำเป็นรายแพ็กเก็ต · local ต่อ router · ต้องเร็วมาก

Routing

กำหนด path ที่ packet จะเดินจาก source ไป destination

network-wide · ใช้ routing algorithm · ผลลัพธ์ลง forwarding table

Path และ “เส้นทางที่ดี”

  • Path = ลำดับของ router ที่ packet ผ่านจากผู้ส่งถึงผู้รับ
  • คำว่า “ดี” อาจหมายถึง cost ต่ำสุด, เร็วสุด หรือ คับคั่งน้อยสุด
  • Routing ถูกเรียกว่าเป็นหนึ่งใน top-10 networking challenge

เหตุผลที่ SDN น่าสนใจ

  • จัดการเครือข่ายง่ายขึ้น ลดการตั้งค่า router ผิดพลาด และยืดหยุ่นกว่าในการจัดการ traffic

ทุก node รู้ topology ทั้งหมด แล้วแต่ละ router รัน Dijkstra ด้วยตัวเอง

ข้อดี

ทุกคนเห็นภาพรวมเดียวกัน — คำนวณเส้นทางที่ถูกต้องตาม topology ปัจจุบันได้ตรงไปตรงมา

ROUTING · DISTANCE-VECTOR

Distance-Vector (DV)

แต่ละ node เก็บค่าประมาณ cost ไปทุกปลายทาง แล้วแลกเปลี่ยนกับเพื่อนบ้าน

DV · ส่งให้เพื่อนบ้าน → รับ DV ใหม่ → BELLMAN-FORD → ทำซ้ำ
Distance vectorcost ไปทุกปลายทาง
→

→
Bellman-Fordอัปเดตค่า
→
แจ้งเมื่อเปลี่ยนself-stopping

คุณสมบัติ

  • Iterative, asynchronous — แต่ละรอบเกิดจาก link cost เปลี่ยน หรือได้รับ DV จากเพื่อนบ้าน
  • Distributed, self-stopping — แจ้งเพื่อนบ้านเฉพาะเมื่อ DV ตัวเองเปลี่ยน

สมการที่ใช้

Dx(y)= minv { c(x,v) + Dv(y) }

v คือเพื่อนบ้านของ x — เลือกตัวที่ให้ค่าต่ำสุด

ALGORITHM · DIJKSTRA

Dijkstra Algorithm

หา least-cost path จาก source ไปทุก node — ใช้ใน Link-State

สัญลักษณ์ความหมาย
c(x,y)cost ของ link ตรง x→y (∞ ถ้าไม่ใช่เพื่อนบ้านกัน)
D(v)ค่าประมาณปัจจุบันของ cost ต่ำสุดจาก source ไป v
p(v)predecessor — node ก่อนหน้า v บน path
N'เซตของ node ที่รู้ least-cost path แน่นอนแล้ว

ขั้นตอน

Initialization:
  N' = {u}
  for all nodes v:
    if v adjacent to u: D(v) = c(u,v)
    else:               D(v) = ∞

Loop:
  find w not in N' such that D(w) is a minimum
  add w to N'
  update D(v) for all v adjacent to w and not in N':
      D(v) = min( D(v), D(w) + c(w,v) )
until all nodes in N'

สรุปสั้น ๆ: เลือกตัวที่ใกล้สุด → ยืนยัน → อัปเดตเพื่อนบ้าน → ทำซ้ำ

ALGORITHM · BELLMAN-FORD

Bellman-Ford Equation

สมการหัวใจของ Distance-Vector — เลือกเพื่อนบ้านที่ให้ cost รวมต่ำสุด

Dx(y) = minv { c(x,v) + Dv(y) }

min ครอบคลุมทุกเพื่อนบ้าน v ของ x · v ที่ให้ค่าต่ำสุดคือ next hop ไป y

เพื่อนบ้านของ u รายงาน

  • Dv(z) = 5
  • Dw(z) = 3
  • Dx(z) = 3

คำนวณ

Du(z)= min{ 2+5, 1+3, 5+3 } = 4

node ที่ให้ค่าต่ำสุดคือ x จึงเป็น next hop บนเส้นทางไป z

Exam Tipโจทย์ BF มักให้ค่า c(x,v) และ Dv(y) ของเพื่อนบ้าน แล้วถาม Dx(y) กับ next hop — บวกให้ครบทุกเพื่อนบ้านแล้วเลือกค่าน้อยสุด

OSPF (Open Shortest Path First)

OSPF แบบ flat

ทุก router ใน AS อยู่ในโดเมนเดียว แล้ว flood LSA ถึงกันทั้งหมด

คุณสมบัติ

  • “Open” = เปิดเผยสาธารณะ
  • flood link-state advertisement ไปทุก router ใน AS โดยส่งตรงบน IP (ไม่ใช้ TCP/UDP)
  • เลือก metric ได้หลายแบบ เช่น bandwidth, delay
  • ทุก router มี topology ครบ แล้วใช้ Dijkstra
  • ข้อความ OSPF มี authentication

BGP Policy & Route Selection

BGP ให้ policy มาก่อน performance — ลองกดดูลำดับการเลือก route

Import / Export policy

gateway ที่รับประกาศใช้ import policy ตัดสินใจรับหรือปฏิเสธ (เช่น “ไม่ผ่าน AS Y เด็ดขาด”) และ policy ยังกำหนดว่าจะประกาศต่อให้เพื่อนบ้านหรือไม่

Hot potato routing

เมื่อมีหลาย gateway ให้ออกได้ เลือก gateway ที่มี intra-domain cost ต่ำสุด โดยไม่สนใจ cost ฝั่ง inter-domain (เช่น 2d เลือก 2a แม้จะผ่าน AS มากกว่า)
