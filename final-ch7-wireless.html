WIRELESS · NETWORK TYPES

Infrastructure vs Ad Hoc

ไม่ใช่ทุก wireless network ที่เชื่อมต่อกับเครือข่ายใหญ่ — ad hoc network ให้ device จัดเครือข่ายกันเองโดยไม่มีอุปกรณ์กลาง

Infrastructure-based

  • มี base station/AP เป็นจุดเชื่อมต่อกับเครือข่ายที่ใหญ่กว่า
  • device สื่อสารผ่าน AP/BS
  • ตัวอย่าง: Wi-Fi ในบ้าน/มหาวิทยาลัย, 4G/5G
ข้อดีเชื่อมต่อ Internet, จัดการ authentication และ mobility ได้จากโครงข่าย

Ad hoc

  • ไม่มี base station หรือ AP
  • อุปกรณ์จัดเครือข่ายและสื่อสารกันเอง
  • ตัวอย่าง: Bluetooth piconet, VANET, sensor network บางแบบ
ข้อสังเกตอาจไม่เชื่อมกับ Internet เลย — เป็นเครือข่ายเฉพาะกิจระหว่าง device

SNR & Shannon Capacity

SNR คืออัตราส่วนกำลังสัญญาณต่อ noise; Shannon บอกขีดจำกัดทางทฤษฎีของอัตราส่งข้อมูลเมื่อมี bandwidth และ SNR

SNRSNR(dB) = 10 · log10(P_signal / P_noise)
ShannonC = B · log2(1 + S/N)
จุดสำคัญS/N ในสูตร Shannon เป็นค่า linear ไม่ใช่ dB; SNR สูง → แยกสัญญาณง่าย → ส่งเร็ว/ผิดพลาดน้อย; SNR = 0 dB → กำลังสัญญาณเท่ากับ noise

แปลง bit เป็น symbol แล้ว modulate บน carrier — ยิ่ง symbol เยอะยิ่งส่งได้เร็ว แต่ต้องมี SNR ดีพอ

วิธีหลักการsymbol

BPSKเปลี่ยน phase 180°2

16-QAM4 ระดับ I × 4 ระดับ Q16 (4 bits/symbol)
64-QAM8 ระดับ I × 8 ระดับ Q64 (6 bits/symbol)
Constellation diagramจุด = symbol; ระยะจาก origin = amplitude; มุม = phase; receiver เลือก symbol ใกล้สุด

Adaptive modulation

  • SNR ดี → ใช้ modulation สูง เช่น 64-QAM เพื่อเพิ่ม rate
  • SNR แย่ → ใช้ modulation ต่ำ เช่น QPSK เพื่อลด error
  • เปลี่ยน scheme ตาม channel แบบ on-the-fly
16-QAM ตัวอย่าง11.5 Mbps
64-QAM ตัวอย่าง26.9 Mbps

WI-FI · MAC

CSMA/CA

802.11 ใช้ CSMA/CA ไม่ใช่ CSMA/CD เพราะตรวจจับ collision ขณะส่งได้ยาก, dynamic range สูง และ hidden terminal ทำให้ฟังอย่างเดียวไม่พอ

ขั้นตอนส่ง

  1. channel idle เป็นเวลา DIFS → ส่ง frame ทันที; 802.11 ไม่ทำ collision detection ระหว่างส่ง
  2. channel busy → เริ่ม random backoff; timer นับถอยหลังขณะ idle
  3. receiver ได้รับ frame ถูกต้อง → ตอบ ACK หลัง SIFS
  4. sender ไม่ได้รับ ACK → เพิ่ม random backoff แล้วลองใหม่

MOBILITY · COMPARE

Wi-Fi vs 5G Mobility

Wi-Fi จัดการ mobility ในระดับ link layer ภายใน ESS; 5G ใช้ RAN + core mobility ผ่าน handover และ UPF tunnel switch
