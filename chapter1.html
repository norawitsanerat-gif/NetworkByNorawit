NETWORK BASICS

Computer Network คืออะไร?

Computer Network คือการที่อุปกรณ์หลายเครื่องสามารถเชื่อมต่อและสื่อสารแลกเปลี่ยนข้อมูลกันได้

LIVE DEMO · กดปุ่มเพื่อทดลอง

ลองนึกภาพง่าย ๆ

มือถือของเราส่งข้อความไปหา Server ข้อมูลจะถูกตัดเป็นชิ้นเล็ก ๆ (Packet) แล้วเดินทางผ่าน Router ไปตามเครือข่าย จนถึงปลายทาง — เหมือนส่งจดหมายที่ถูกแบ่งใส่ซองหลายซอง

นิยามแบบวิชาการ

Computer Network คือกลุ่มของอุปกรณ์อิสระตั้งแต่ 2 เครื่องขึ้นไปที่เชื่อมต่อกันด้วยสื่อกลาง เพื่อแลกเปลี่ยนข้อมูลและใช้ทรัพยากรร่วมกัน

Exam Tipข้อสอบชอบถามว่า "ข้อใดคือตัวอย่าง Network" — ให้มองหา "อุปกรณ์หลายเครื่อง + เชื่อมต่อ + แบ่งปันข้อมูล"

NETWORK BASICS

ทำไมต้องมีเครือข่าย? (Benefits of Network)

ถ้าไม่มีเครือข่าย เราจะต้องสลับ USB ไปมาเพื่อส่งไฟล์ — Network ทำให้ทุกอย่างเชื่อมต่อและแบ่งปันกันได้

จำง่าย ๆประโยชน์หลักของ Network = แบ่งปัน (Share) + สื่อสาร (Communicate) + รวมศูนย์ (Centralize)

Five Components of Data Communication

การสื่อสารข้อมูลจะเกิดขึ้นได้ ต้องมีองค์ประกอบครบ 5 อย่าง ถ้าขาดอย่างใดอย่างหนึ่ง การสื่อสารจะไม่สมบูรณ์

Protocol = Communication Rules

กฎการสื่อสารที่ทั้งสองฝ่ายตกลงกัน — คอยกำกับการส่งข้อมูลตลอดทั้งกระบวนการ

องค์ประกอบ 5 อย่าง

ทุกครั้งที่เราส่งข้อมูล — ไม่ว่าจะส่ง LINE, โหลดเว็บ หรือดูวิดีโอ — ข้อมูลต้องผ่านองค์ประกอบเหล่านี้เสมอ ลองดูการ์ดด้านล่างทีละใบ

ตัวอย่าง: ส่ง LINE

เรา (Sender) พิมพ์ข้อความ (Message) ส่งผ่านอินเทอร์เน็ต (Medium) ไปยังมือถือเพื่อน (Receiver) โดยทุกฝ่ายใช้ภาษาและรูปแบบเดียวกัน (Protocol)

Protocol ต้องมีอะไรบ้าง

Syntax — รูปแบบของข้อมูล เช่น ขึ้นต้นและจบอย่างไร
Semantics — ความหมายของแต่ละส่วน เช่น ข้อมูลนี้คืออะไร
Timing — จังหวะเวลา เช่น เมื่อไหร่ควรส่ง และรอคำตอบนานแค่ไหน

จำแบบนี้Protocol = ภาษาและมารยาทของการสื่อสาร ถ้าไม่มี Protocol อุปกรณ์จะ "พูดกันไม่รู้เรื่อง" เหมือนคนที่พูดคนละภาษา
Exam Tipตัวอย่าง Protocol ที่ข้อสอบชอบ: HTTP (เปิดเว็บ), TCP (ส่งข้อมูลให้ครบ), IP (กำหนดที่อยู่)

จากเครือข่ายทหารสู่เครือข่ายที่เชื่อมคนทั้งโลก — กดการ์ดแต่ละยุคเพื่อดูรายละเอียด

INTERNET

Internet vs World Wide Web

หลายคนใช้คำว่า "Internet" และ "Web" แทนกัน แต่จริง ๆ แล้วไม่เหมือนกัน

INTERNET

โครงสร้างเครือข่ายขนาดยักษ์ที่เชื่อมต่ออุปกรณ์ทั่วโลกเข้าด้วยกัน — เป็น "โครงสร้างพื้นฐาน" (Infrastructure)

ประกอบด้วย: สายเคเบิล, Router, Server, อุปกรณ์ทุกชนิดที่ต่อถึงกัน

WORLD WIDE WEB

บริการหนึ่งที่วิ่งอยู่บน Internet — ระบบของหน้าเว็บและลิงก์ที่เราเปิดผ่าน Browser

Web, Email, Game, Video Call ล้วนเป็นบริการที่ "วิ่งบน" Internet ทั้งหมด

Analogy — จำง่ายมากInternet = ถนน 🛣️ (โครงสร้าง) ส่วน Web = รถ 🚗 (ยานพาหนะที่วิ่งบนถนน) — บน Internet มีบริการหลายชนิดวิ่งอยู่ ไม่ใช่แค่ Web
